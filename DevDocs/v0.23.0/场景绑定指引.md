## 1. 在场景中选中 UITitle 组件

`Title.unity` → Hierarchy 中找到挂 `UITitle` 的对象（通常名如 `TitleUI` / `UITitle`），在 Inspector 中查看 `UITitle (Script)` 组件。

### 1.1 需检查/修正的现有面板引用

组件上已有的面板引用，其中 **`LLM Memory 子面板` 当前可能绑错对象**：

| 字段 | 应指向 | 现状提示 |
|------|--------|----------|
| `LLM Agent 子面板` | 场景中的 `PanelLLMAgent` | 正确 |
| `LLM Memory 子面板` | 场景中的 `PanelLLMMemory` | ⚠️ 检查是否误绑成了 `PanelLLMAgent`（两个字段指向同一对象即为错误） |

| `Reranker 子面板` | `PanelReranker` | 正确 |

> 若发现 `LLM Memory 子面板` 与 `LLM Agent 子面板` 指向同一对象，请将其改拖到真正的 `PanelLLMMemory` 节点。

## 2. 绑定 12 个 API 配置输入框（TMP_InputField）

`UITitle` 组件新增了 **4 组 × 3 个** `TMP_InputField` 引用，需要从场景中对应子面板拖拽绑定。

场景结构约定（每个配置子面板下都有 3 个子节点）：

```
PanelLLMAgent
  ├── PanelBase      ← 对应「Base URL」输入框
  ├── PanelApiKey    ← 对应「API Key」输入框
  └── PanelModel     ← 对应「Model」输入框
```

> `PanelBase` / `PanelApiKey` / `PanelModel` 内的实际输入框组件是 **TextMeshPro `TMP_InputField`**（不是老的 UGUI InputField）。

### 2.1 LLM Agent 子面板

| UITitle 字段 | 拖入对象 |
|--------------|----------|
| `API 配置：LLM Agent 子面板` → `Agent Base 输入框` | `PanelLLMAgent/PanelBase` 上的 `TMP_InputField` |
| `Agent Key 输入框` | `PanelLLMAgent/PanelApiKey` 上的 `TMP_InputField` |
| `Agent Model 输入框` | `PanelLLMAgent/PanelModel` 上的 `TMP_InputField` |

### 2.2 LLM Memory 子面板

| UITitle 字段 | 拖入对象 |
|--------------|----------|
| `API 配置：LLM Memory 子面板` → `Memory Base 输入框` | `PanelLLMMemory/PanelBase` 上的 `TMP_InputField` |
| `Memory Key 输入框` | `PanelLLMMemory/PanelApiKey` 上的 `TMP_InputField` |
| `Memory Model 输入框` | `PanelLLMMemory/PanelModel` 上的 `TMP_InputField` |

### 2.3 Embedding 子面板

| UITitle 字段 | 拖入对象 |
|--------------|----------|
| `API 配置：Embedding 子面板` → `Embedding Base 输入框` | `PanelEmbedding/PanelBase` 上的 `TMP_InputField` |
| `Embedding Key 输入框` | `PanelEmbedding/PanelApiKey` 上的 `TMP_InputField` |
| `Embedding Model 输入框` | `PanelEmbedding/PanelModel` 上的 `TMP_InputField` |

### 2.4 Reranker 子面板

| UITitle 字段 | 拖入对象 |
|--------------|----------|
| `API 配置：Reranker 子面板` → `Reranker Base 输入框` | `PanelReranker/PanelBase` 上的 `TMP_InputField` |
| `Reranker Key 输入框` | `PanelReranker/PanelApiKey` 上的 `TMP_InputField` |
| `Reranker Model 输入框` | `PanelReranker/PanelModel` 上的 `TMP_InputField` |

> 若某个子面板内还没有输入框，需要自行创建一个 `TMP_InputField`（右键 UI → Text - TextMeshPro → Input Field）并命名 `PanelBase` / `PanelApiKey` / `PanelModel`。

## 3. 保存配置弹窗按钮绑定

保存确认弹窗（Inspector 里 `UITitle` 的 `保存配置确认弹窗` 已指向 `mSaveConfigMsgBox`）。

在弹窗内：
- **「保存」按钮**的 `OnClick` 挂 `UITitle.OnConfirmSaveConfig`（`OnConfirmSaveConfig()` 无参）
- **「取消」按钮**的 `OnClick` 挂 `UITitle.OnCancelSaveConfig`（`OnCancelSaveConfig()` 无参）

> 注意：若场景里之前绑的是 `OnConfirmSaveConfig`（旧占位实现），**无需改名**——我保留了这个方法名并在其中实现了真正的保存逻辑，直接沿用即可。

---

## 4. 无 API Key 弹窗绑定

`UITitle` 的 `无API Key弹窗` 已指向 `mNoApiKeyMsgbox`。该弹窗的**确认按钮**只需关闭自身：
- 按钮 `OnClick` 挂 `GameObject.SetActive(false)`（拖 `mNoApiKeyMsgbox` 自身，选 `GameObject.SetActive` 反选 false）
- 或依赖 `UIMsgBox` 的默认 ESC → Btn1 行为（ESC 触发确认即关闭）

## 5. 入口按钮（无需改动，仅确认）

`新游戏` / `继续游戏` 按钮的 `OnClick` 仍指向 `UITitle.OnClickNewGame` / `UITitle.OnClickContinueGame`（方法名未变），**逻辑已在代码内接管**：
- 配置不完整 → 弹「无 API Key」提示并拦截
- 配置完整 → 自动发 `InitRequest` 等待 Python 初始化 → 进入 GameFlow

无需重新绑定按钮。

## 6. 保存后产物与自检

1. 在游戏里打开配置面板填好 12 项 → 保存 → 确认生成文件：
   ```
   Src/Data/Config/api_config.json
   ```
   （该文件已在 `.gitignore` 中，含 Key 明文不会入库。）
2. `api_config.json` 内容形如：
   ```json
   {
       "agentApiBase": "https://...",
       "agentApiKey": "sk-...",
       "agentModel": "...",
       "memoryApiBase": "...",
       "memoryApiKey": "...",
       "memoryModel": "...",
       "embeddingApiBase": "...",
       "embeddingApiKey": "...",
       "embeddingModel": "...",
       "rerankerApiBase": "...",
       "rerankerApiKey": "...",
       "rerankerModel": "..."
   }
   ```
   （字段名与 Python `config/api_config_loader.API_CONFIG_KEYS` 的 12 项对应。）
3. 重启 PythonServer（无 Key 模式启动），在 Title 点「新游戏」→ 应看到 Python 日志打印 `[api_config] 已注入 N 项配置` 并完成 `MemoryManager.initialize()`。

## 7. 常见问题

| 现象 | 处理 |
|------|------|
| 打开配置子面板，输入框空白 | 检查 12 个 `TMP_InputField` 引用是否都绑上了；`api_config.json` 不存在时空白是正常的（首次配置） |
| 改完输入框后按 ESC 不弹保存确认 | 确认 `mSaveConfigMsgBox` 已绑定；ESC 由 `UIMsgBox` 接管时 `UITitle` 不处理（正常） |
| 点「新游戏」提示无 API Key 但明明填了 | 确认 12 项**全部**非空（`IsComplete()` 要求全填） |
| Python 日志无 `[api_config]` 注入 | 确认 `api_config.json` 生成在 `Src/Data/Config/` 下、字段名正确 |
