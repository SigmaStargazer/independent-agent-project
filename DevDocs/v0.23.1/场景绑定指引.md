## 1. 三个复制按钮脚本挂载（需求一）

| 脚本 | 挂载对象 | OnClickCopy 行为 |
|------|----------|------------------|
| `UILLMAgent` | `PanelLLMAgent`（根节点） | 把 Memory 组 Base/Key/Model 复制到当前（Agent）面板 3 个文本框 |
| `UILLMMemory` | `PanelLLMMemory`（根节点） | 把 Agent 组配置复制到当前（Memory）面板 |
| `UILLMRerank` | `PanelReranker`（根节点） | 把 Agent 组配置复制到当前（Reranker）面板（Graphiti 用 LLM 做 rerank，常与 Agent 同模型） |

每个脚本有一个 `mSetting` 字段，指向 **UIConfig 上的 UISetting 组件**，**必须绑定**否则复制无效。

### 1.1 复制按钮挂 OnClick

各面板的「复制」按钮（把另一组配置复制到此处）`OnClick` 绑定到对应脚本的 `OnClickCopy`：

| 面板 | 按钮 OnClick 目标对象 | 方法 |
|------|------------------------|------|
| `PanelLLMAgent` | 本面板上的 `UILLMAgent` | `UILLMAgent.OnClickCopy` |
| `PanelLLMMemory` | 本面板上的 `UILLMMemory` | `UILLMMemory.OnClickCopy` |
| `PanelReranker` | 本面板上的 `UILLMRerank` | `UILLMRerank.OnClickCopy` |

> 复制只改文本框，**不自动保存**；用户按 ESC 走既有 `MsgboxSaveApiKey` 流程决定是否落盘。

## 2. MsgboxSaveApiKey（4 个模型配置 Panel 退出专用弹窗）

v0.23.1 起，从任一模型配置子面板 ESC 退出（有变更）固定弹 **MsgboxSaveApiKey**（替代原 MsgboxSaveSetting；后者本版不再使用，保留备用）。

### 2.1 UITitle 新增引用

选中挂 `UITitle` 的对象，拖入以下引用（Inspector 序列化字段）：

| UITitle 字段 | 拖入对象 |
|--------------|----------|
| `Save Api Key Msg Box`（`mSaveApiKeyMsgBox`） | `MsgboxSaveApiKey` GameObject |
| `Model Testing Msgbox`（`mModelTestingMsgbox`） | `MsgboxModelTesting`（需挂 `UIMsgBox` 组件） |
| `Model Available Msgbox`（`mModelAvailableMsgbox`） | `MsgboxModelAvailable`（需挂 `UIMsgBox` 组件） |
| `Model Unavailable Msgbox`（`mModelUnavailableMsgbox`） | `MsgboxModelUnavailable`（需挂 `UIMsgBox` 组件） |

> 3 个结果弹窗**必须挂 `UIMsgBox` 组件**（否则 `SetText` / `AnyActive` 不工作）。`Awake` 会自动把所有新增弹窗 `SetActive(false)`。

### 2.2 MsgboxSaveApiKey 按钮绑定（三按钮）

| 按钮 | 文案 | 行为 | 绑定到 |
|------|------|------|--------|
| **Btn1** | 取消 | 只关弹窗，**停留当前子面板**（不切换） | `UITitle.CloseSaveApiKeyMsgBox` |
| **Btn2** | 退出 | **不保存**，关弹窗 → 固定返回 **PanelSetting** | `UITitle.OnExitSaveApiKey` |
| **Btn3** | 测试后保存 | **不保存**，关弹窗 → 开始测试当前面板模型（弹 ModelTesting） | `UITitle.OnConfirmTestApiKey` |

> **关键**：Btn3「测试后保存」**不写盘**；只有测试通过后，在 `MsgboxModelAvailable` 点「保存退出」才写盘（避免不可用配置覆盖原可用配置）。

### 3.1 MsgboxModelTesting（测试中，单按钮）

## 5. 验收自检（v0.23.1）

### 需求一（复制按钮）
1. **Agent → Memory**：Agent 面板配好 → 进 Memory 面板点「复制」→ 三个文本框被 Agent 配置填充 → ESC → 弹 `MsgboxSaveApiKey` → 保存后写盘正确。
2. **Memory → Agent**：对称验证。
3. **Agent → Reranker**：Reranker 面板点「复制」→ 被 Agent 配置填充。

### 需求二（测试后保存）
4. 任一模型配置面板 ESC（有变更）→ 弹 `MsgboxSaveApiKey`；Btn1 取消停留、Btn2 退出固定返回 PanelSetting（不保存）。
5. 点「测试后保存」→ **不保存、不切面板**，先弹 `MsgboxModelTesting`。
6. 正常配置 → 弹 `MsgboxModelAvailable`，此时 `api_config.json` **未被写入**；点「继续配置」留当前面板；点「保存退出」→ 写盘 + 返回 PanelSetting。
7. 改错 Key → 弹 `MsgboxModelUnavailable`（显示失败原因），`api_config.json` **保持原值**；点「继续配置」留当前面板；点「退出」→ 不保存返回 PanelSetting。
8. 点「测试后保存」后在 `MsgboxModelTesting` 点「取消」→ 关弹窗停留当前面板，**不弹结果弹窗**。
9. 只测当前面板那组模型，不测试其他 3 组（Python 日志 `ApiTestRequest::category=...` 确认）。
10. 测试后 Python 仍为零系统（`MemoryManager.is_initialized == False`、无 Agent）。

### 需求二补充（v0.23.1 修复后，2026-08-22）
11. **Reranker 面板配 `deepseek-v4-flash`（经复制按钮从 Agent 组拷贝）→ 测试应通过**（已修复：rerank 请求统一关闭 thinking，Reasoning 模型可用于 Graphiti）。若仍失败，检查 Python 是否重启加载了新代码。
12. **Reranker 面板不要配 `gte-rerank-v2`**（DashScope 专用 rerank 模型，走独立协议，无法用于 Graphiti LLM 二分类，测试会如实报不可用）。

## 6. 常见问题

| 现象 | 处理 |
|------|------|
| 点复制无反应 | 检查复制脚本是否挂对面板、`mSetting` 是否拖到 UIConfig 上的 UISetting |
| 点「测试后保存」无反应 | 检查 `MsgboxSaveApiKey` 的 Btn3 是否绑定 `UITitle.OnConfirmTestApiKey` |
| 结果弹窗不弹 | 检查 3 个结果弹窗是否挂了 `UIMsgBox` 组件、`UITitle` 的 3 个 `*Msgbox` 引用是否绑定 |
| Unavailable 无失败原因 | 确认结果弹窗挂了 `UIMsgBox`（`SetText` 依赖 `WarningTxt`） |
| 测试长时间无响应 | Python 侧超时 30s 会返回失败；确认 PythonServer 已启动且端口连通 |
