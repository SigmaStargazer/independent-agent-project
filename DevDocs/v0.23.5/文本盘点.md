### 3.4 Msgbox（Bootstrap 场景 = TransitionUI 错误提示弹窗，需切换）

Bootstrap 场景有 **1 个** Msgbox prefab 实例（PrefabInstance 2144841533），挂在 `TransitionUIRoot` 下，**默认隐藏（m_IsActive=0）**。

> 🔍 **已核实（用户 2026-09-03 追问后确认）**：这个 Msgbox 实例**就是 `TransitionUI` 的错误提示弹窗**，不是遗留弹窗。`TransitionUI`（挂 `TransitionUIRoot`，`dontDestroyOnLoad=1`）的序列化引用：
> - `errorPanel: {fileID: 2144841536}` ← 该 Msgbox 实例根
> - `errorText: {fileID: 2144841535}` ← 该 Msgbox 实例主文本（WarningTxt）
>
> Bootstrap 加载出错时，`FlowExecutor` 捕获异常 → `TransitionUI.Instance.ShowError(e.Message)` → 激活 `errorPanel` 并 `SetText` 设置主文本。**答案：Bootstrap 出错弹出的就是 Bootstrap 场景里的这个 Msgbox**，由 `TransitionUI.ShowError` 驱动。
>
> ⚠️ 注意：此 Msgbox 实例**未挂 `UIMsgBox` 脚本**（仅被 `TransitionUI` 字段引用），因此按钮不受 `UIMsgBox` 管理。场景覆盖了「好的」按钮文本，但**主文本由 `ShowError` 运行时动态设置**（即异常消息 `e.Message`，中英混合）。

| 元素 | 当前文本 | 说明 |
|------|----------|------|
| 主文本 | 运行时由 `ShowError(e.Message)` 设置 | 动态传入，中英混合（异常消息） |
| 按钮2 | 好的 | 场景覆盖（静态，可走文案表） |

> 切换方案要点：主文本是运行期异常文本，无法静态翻译（同 B-15）；「好的」按钮文本是静态的，可走文案表。

## 四、当前文案表基础设施（UITextProvider）

- 文件：`Assets/Scripts/.../UI/UITextProvider.cs`
- 文案表：`Assets/Resources/UI/strings_ChineseSimplified.json`（UTF-8 扁平 JSON）
- 强类型：`UITextKey` 枚举（Inspector 下拉选择）
- 已注释说明：「未来加语言 = 新增一个语言文件 + 运行时按当前语言加载，代码/场景零改动」

**这是语言切换的天然入口**，但当前存在两个缺口：
1. 资源路径 `ResourcePath = "UI/strings_ChineseSimplified"` **写死**，无法切换语言文件。
2. 大量文本（主菜单按钮、Msgbox、FlowStep.DisplayName）**尚未接入** UITextProvider。

## 五、Excel 配置建议

需求方提出「各语言文本的配置建议用 Excel」。建议方案：

- 用 Excel 维护**一张总表**（列：key / 中文 / English / 备注 / 所属模块），策划填写。
- 构建或运行时把 Excel 导出为各语言的 JSON（如 `strings_ChineseSimplified.json` / `strings_English.json`）放入 `Assets/Resources/UI/`。
- 运行时按当前语言加载对应文件（改造 `UITextProvider` 支持运行时切换语言 + 事件通知 UI 刷新）。

> 导出工具可做成 Unity 编辑器扩展或命令行脚本，此部分需在方案阶段细化。
