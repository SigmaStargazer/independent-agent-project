## 1. 背景与目标

当前 Title 场景一进入就显示主菜单（开始 / 继续 / 新游戏确认弹窗）。产品希望加入业界常见的「按任意按钮」启动画面（Press Any Button），作为进入主菜单前的一道仪式化过渡：刚进 Title 显示「按任意按钮」，按键后才展示主菜单；主菜单按 ESC 可退回该画面。

## 2. 范围

### 2.1 本期包含

- 新增「按任意按钮」启动画面（UI 元素 + 交互逻辑）。
- 启动画面 → 主菜单 的单向进入（按任意按钮）。
- 主菜单 → 启动画面 的返回（按 ESC）。
- 「按任意按钮」提示文字的**呼吸闪烁动画**（补充开发内容，方案见 solution.md §3.3.5）。
- 与现有「新游戏确认弹窗」（`WarningPanel`）互不干扰。

### 2.2 本期不包含

- 启动画面以外的淡入淡出/转场特效（如进入 Title 的整体淡入、主菜单切换过渡）。
- 音频（按键音效）。
- 手柄/键盘以外的触屏适配差异处理。
- 修改 `ReturnToTitleFlow` 以外的任何游戏流程。

## 3. 用户与场景

| 角色 | 场景 | 期望结果 |
|------|------|----------|
| 玩家 | 首次进入 Title | 看到「按任意按钮」，按键后出现主菜单 |
| 玩家 | 主菜单按 ESC | 回到「按任意按钮」画面 |
| 玩家 | 启动画面按 ESC | 不退出游戏，仅当作普通按键进入主菜单 |

## 4. 功能需求

### 4.1 启动画面

- 进入 Title 场景时，默认显示「按任意按钮」提示，隐藏 `PanelTitle` 主菜单。
- 提示文字可配置（默认「按任意按钮」）。

### 4.2 按键进入主菜单

- 在启动画面下，检测到任意有效输入（键盘任意键 / 鼠标任意键）后，进入主菜单：
  - 隐藏启动画面；
  - 显示 `PanelTitle`。
- 无效输入需过滤：
  - 忽略 `Input.anyKey` 的持续按住（仅响应 `anyKeyDown` 沿）；
  - 忽略滚轮等非"按下"事件；
  - 忽略输入轴死区抖动。

### 4.3 ESC 返回启动画面

- 在主菜单显示状态下，按 ESC（项目旧输入 `Menu` 轴 = escape）隐藏主菜单面板、显示「按任意按钮」启动画面。
- 在设置面板显示状态下，按 ESC 返回主菜单（逐级返回）。
- 在启动画面显示状态下，ESC 作为普通按键进入主菜单（**不退出游戏**）。

### 4.4 提示文字闪烁动画

- 「按任意按钮」提示文字在启动画面激活时**平滑呼吸闪烁**（Alpha 在最低~最高间正弦循环）。
- 进入主菜单后停止闪烁；返回启动画面后恢复闪烁。
- 闪烁参数可配置（周期 / 最亮 / 最暗），留空则不做动画（向后兼容）。

## 5. 非功能需求

- 复用项目现有的**旧版 Input Manager**（Unity 2021.3.8f1c1，`activeInputHandler=0`，未装 Input System），**不新增** Input System 依赖。
- 不新增第三方依赖。
- 状态切换逻辑清晰、可单元测试（纯状态判定函数）。
