# PRD - v0.22.3 main 运行终端日志落盘

> **状态**：已确认

> **最后更新**：2026-07-10

## 1. 背景与目标

目前 `Src/PythonServer/logs/` 下仅有 `prompts/{agent名}/{时间戳}.log`，由 `agent_interuptible._save_prompt_log` 写入，只保存各 agent 每轮推理的完整 prompt。

`main.py` 运行期间向终端输出了大量信息（生命周期事件、工具回调、异常 traceback、性能节点等），这些信息**只显示在控制台**，进程结束后即丢失。开发与训练复盘时常常需要回看「某次运行到底打印了什么」「报错出现在哪个阶段」，而当前只能靠手动复制终端输出或 IDE 的 terminal 缓存。

**目标**：把 `main.py` 每次运行期间输出到终端（stdout/stderr）的全部内容同步落盘为独立日志文件，一次运行一个文件，便于事后检索与复盘。

## 2. 范围

### 2.1 本期包含

- 在 `main.py` 启动时接管 stdout/stderr，把所有终端输出（含 `print`、`perf_print/aperf_print`、未捕获异常 traceback、`logging` 默认输出等）同步写入文件。
- 每次 `main` 运行产出一个独立文件，文件名含启动时间戳。
- 与现有 `logs/prompts/` 共存，互不影响。

### 2.2 本期不包含

- 不改造 `graphiti_core` 内部的 `logging.getLogger` 体系（其默认不输出到终端，本期目标是捕获「终端实际打印内容」，不扩展到模块级结构化日志）。
- 不改写已有 `print` 语句本身（不统一日志格式、不引入 `logging` 替换 `print`），仅做输出流的「镜像落盘」。
- 不做日志轮转 / 自动清理 / 压缩（单次运行一个文件，文件量与运行次数线性相关，后续可按需加）。
- 不涉及 Unity 侧任何改动。

## 3. 用户与场景

| 角色 | 场景 | 期望结果 |
|------|------|----------|
| 开发者 | 训练 Agent 后想回看本次运行的完整终端输出 | 到 `logs/console/` 找到对应时间戳的文件直接阅读 |
| 开发者 | 运行报错但终端已被后续输出刷走 | 在日志文件中检索 traceback 定位阶段 |
| 开发者 | 对比两次训练运行的输出差异 | 两个时间戳文件可直接 diff |

## 4. 功能需求

### 4.1 终端日志文件

- 位置：`Src/PythonServer/logs/console/`（与 `logs/prompts/` 同级）。
- 命名：`{启动时间戳}.log`，格式与现有 prompt 日志一致，采用 `%Y-%m-%d_%H-%M-%S`；同一秒内多次启动加毫秒后缀避免覆盖。
- 编码：UTF-8（遵循 `.cursor/rules/file-encoding.mdc`）。
- 内容：本次 `main` 运行期间 stdout 与 stderr 的全部输出，与终端实时显示一致（按行镜像）。
- 终端显示**不受影响**：原有 `print` 仍实时输出到控制台，文件是额外副本。

### 4.2 启用控制

- 默认开启（无需额外环境变量）。
- 提供环境变量 `CONSOLE_LOG_ENABLED`（默认 `true`），设为 `false` 时跳过落盘，仅保留终端输出。

### 4.3 生命周期

- `main()` 启动时创建文件并开始镜像；`main()` 结束（正常退出或异常退出）时关闭文件并刷新。
- 异常导致进程退出时，已写入的内容不丢失（每行写后即 flush，或使用行缓冲）。

## 5. 非功能需求

- **性能**：落盘采用行缓冲，对终端输出延迟无可感知影响。
- **健壮性**：日志文件创建失败不应阻断 `main` 启动，应降级为「仅终端输出」并打印一条告警。
- **兼容性**：Windows / Linux 均可工作；路径用 `os.path.join` 拼接。

## 6. 验收标准

- [ ] `uv run python main.py` 启动后，`logs/console/` 下出现以启动时间戳命名的 `.log` 文件。
- [ ] 文件内容与终端实际输出一致（含 `print`、性能节点、异常 traceback）。
- [ ] 终端显示行为与未加日志功能时完全一致（实时性、格式不变）。
- [ ] `CONSOLE_LOG_ENABLED=false` 时不生成文件，终端输出正常。
- [ ] `main` 因异常退出时，文件中包含出错前的全部输出。
- [ ] `logs/prompts/` 现有功能不受影响。
