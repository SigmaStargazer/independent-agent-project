# 需求：保存 main 每次运行的终端打印日志

> **来源**：用户口头需求（2026-07-10）
> **状态**：待确认

## 原文

> 新版本需求：目前 logs 里只存了各 agent 的 prompt。现在还需要存一类日志，即 main 每次运行时的终端打印内容。

## 要点理解

1. 现状：`Src/PythonServer/logs/` 下只有 `prompts/` 子目录，按 agent 分别保存每轮推理的完整 prompt。
2. 新增：把 `main.py` 每次运行期间输出到**终端**的全部内容（`print`、性能节点、异常 traceback 等）同步保存到一个日志文件。
3. 每次 `main` 运行产出一个独立文件，便于事后复盘（训练过程、报错定位）。
