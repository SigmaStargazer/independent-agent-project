## 本版本需求来源

本版本需求来自用户在 v0.22.16 验收后的口头表述（2026-08-04 对话）：

> 一个 FSM 的状态，可能对应动画机里的多个状态，例如：
> 1) FSM 在 Idle 的过程中，可能时不时插播一些小动作
> 2) Idle->Run 时，可能插播一个起跑动作，停下时可能插播一个刹车动作
> 3) 跳跃时，会有起跳、上升、最高点上升转下落、下落、着地等动作

经 Agent 分析，三类需求对应三种不同的动画内部流转模式，需要扩展 v0.22.16 的 `SceneObjAnimator` 组件能力。
